# Decodelabs_Task02
Exploratory Data Analysis (EDA) Project

## Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on an e-commerce dataset using Python. The main goal of this project is to analyze the dataset, identify patterns, trends, outliers, and generate meaningful insights using statistical analysis and data visualization techniques.

The project includes data cleaning, preprocessing, descriptive statistics, and visualizations to better understand the dataset.

---

# Objective
- Understand the structure of the dataset
- Perform data cleaning and preprocessing
- Handle missing and duplicate values
- Analyze statistical measures
- Identify trends and outliers
- Create visualizations for better understanding
- Generate meaningful business insights

---

# Dataset Information

The dataset contains e-commerce order details with the following columns:

- OrderID
- Date
- CustomerID
- Product
- Quantity
- UnitPrice
- ShippingAddress
- PaymentMethod
- OrderStatus
- TrackingNumber
- ItemsInCart
- CouponCode
- ReferralSource
- TotalPrice
- Sales

# Steps Performed

## 1. Data Loading
The dataset was loaded using Pandas.

## 2. Data Understanding
Basic dataset information was analyzed using:
- head()
- info()
- shape
- columns

## 3. Data Cleaning
The following preprocessing steps were performed:
- Checked missing values
- Removed duplicate rows
- Converted datatypes
- Created a Sales column

## 4. Statistical Analysis
Descriptive statistics were generated to analyze:
- Mean
- Median
- Count
- Minimum and Maximum values
- Standard deviation

## 5. Exploratory Data Analysis
Different visualizations and analyses were performed:
- Product-wise sales analysis
- Payment method analysis
- Order status analysis
- Sales distribution
- Outlier detection
- Correlation analysis

---

# Key Insights

- Certain products generated higher sales compared to others.
- Some outliers were present in the sales data.
- Online payment methods were used more frequently.
- Most orders were completed successfully.
- Positive relationships were observed between quantity and sales.
- Duplicate records were identified and removed successfully.
